# Еженедельный отчёт по позиционированию трейдеров (EURUSD, XAUUSD) в Telegram

Полностью бесплатная схема: GitHub Actions (расписание) + Telegram Bot API.

## Что внутри
- `sentiment_report.py` — скрипт, который берёт данные и шлёт сообщение в Telegram
- `.github/workflows/daily_report.yml` — расписание запуска (по пятницам в 20:30 UTC, сразу после публикации CFTC)
- `last_report_date.txt` — служебный файл, создаётся автоматически: хранит дату последнего отправленного отчёта

## Шаг 1. Создать Telegram-бота
1. В Telegram найдите `@BotFather`, отправьте `/newbot`.
2. Придумайте имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохраните его.

## Шаг 2. Узнать свой chat_id
1. Напишите своему новому боту любое сообщение в Telegram (например "привет").
2. Откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. В ответе (JSON) найдите `"chat":{"id":XXXXXXXXX` — это ваш `chat_id`.

## Шаг 3. Создать репозиторий на GitHub
1. Зарегистрируйтесь на github.com, если ещё нет аккаунта (бесплатно).
2. Создайте новый репозиторий, например `forex-sentiment-bot`.
3. Загрузите туда файлы `sentiment_report.py` и папку `.github/workflows/daily_report.yml`
   (через веб-интерфейс "Add file → Upload files", сохранив структуру папок).

## Шаг 4. Добавить секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
Добавьте два секрета:
- `TELEGRAM_BOT_TOKEN` — токен из шага 1
- `TELEGRAM_CHAT_ID` — id из шага 2

## Шаг 4.5. Разрешить workflow сохранять файл состояния
Скрипт запоминает дату последнего отправленного отчёта в файле
`last_report_date.txt` — это нужно, чтобы не слать повторно тот же отчёт,
если CFTC вдруг задержит публикацию (например, из-за праздника в США).
Workflow сам коммитит этот файл обратно в репозиторий после каждого запуска,
поэтому нужно разрешить Actions запись в репозиторий:

1. В репозитории откройте **Settings → Actions → General**.
2. Прокрутите вниз до раздела **Workflow permissions**.
3. Выберите **"Read and write permissions"**.
4. Нажмите **Save**.

Без этого шага сам отчёт в Telegram будет приходить нормально, но шаг
"Save last sent state" будет падать с ошибкой доступа при попытке
закоммитить файл.

## Шаг 5. Проверить вручную
1. Перейдите во вкладку **Actions** репозитория.
2. Выберите workflow "Weekly CFTC Positioning Report".
3. Нажмите **Run workflow** (это возможно благодаря строке `workflow_dispatch` в файле).
4. Через минуту проверьте Telegram — должно прийти сообщение.

Если сообщение не пришло — откройте лог запуска в Actions и посмотрите на ошибку
(чаще всего это неверный токен/chat_id либо изменившаяся структура страницы-источника).

## Шаг 6. Готово
Дальше скрипт будет запускаться автоматически по пятницам в 20:30 UTC —
вскоре после того, как CFTC публикует новые данные. Если новых данных ещё
нет (например, из-за праздника в США), скрипт сам определит это по дате
отчёта и просто пропустит отправку — сообщение придёт при следующем
успешном запуске, как только выйдут новые данные.

Чтобы изменить время или частоту запуска, отредактируйте строку
`cron: '30 20 * * 5'` в файле `.github/workflows/daily_report.yml`
(формат: минута час * * день_недели, время в UTC, 5 = пятница).

## Важно понимать про источник данных
Скрипт использует официальный бесплатный API американского регулятора CFTC —
"Commitments of Traders" (данные о позициях крупных трейдеров по фьючерсам
на евро и золото). Это открытые государственные данные без защиты от ботов,
поэтому они надёжно работают из GitHub Actions (в отличие от скрапинга
брокерских сайтов вроде Myfxbook, которые блокируют запросы с серверов).

**Важная оговорка:** CFTC публикует эти данные **раз в неделю** (по пятницам,
по состоянию на предыдущий вторник), а не ежедневно. Поэтому в большинстве
дней сообщение будет показывать те же цифры, что и днём ранее — новая дата
"по состоянию на" появится только раз в неделю. Это разумный компромисс для
полностью бесплатного и надёжного решения.

Если CFTC когда-нибудь переименует контракты в датасете, может понадобиться
поправить точные названия рынков (`MARKETS`) в файле `sentiment_report.py` —
в скрипте уже есть запасной вариант поиска по подстроке на этот случай.

Также помните: это позиционирование крупных спекулянтов (не гарантия
направления цены) — используйте как один из контекстных факторов, а не как
самостоятельный сигнал для сделки.

# Второй отчёт: подготовка к неделе (календарь + диапазоны + уровни)

Это отдельный, независимый отчёт — свой скрипт (`weekly_market_prep.py`) и свой
workflow (`.github/workflows/weekly_market_prep.yml`). Он не трогает и не влияет
на первый отчёт (CFTC), присылается отдельным сообщением в тот же Telegram-бот.

## Что внутри
- Экономический календарь по USD на неделю (High/Medium impact события) —
  источник: бесплатный публичный фид Forex Factory
- Средний недельный диапазон (за последние 8 недель) по EURUSD и XAUUSD
- Ключевые уровни на неделю: high/low прошлой недели + классические пивоты
  (P, R1, R2, S1, S2) по EURUSD и XAUUSD

Расписание: каждое воскресенье в 15:00 UTC (можно поменять строку
`cron: '0 15 * * 0'` в файле workflow).

## Шаг 1. Получить бесплатный ключ Twelve Data
Для диапазонов и уровней используется Twelve Data — бесплатный API для
финансовых данных, который в отличие от некоторых других поддерживает
именно XAU/USD (золото), а не только валютные пары. Регистрация без карты.

1. Откройте https://twelvedata.com/ → Get free API key (или Sign up)
2. Зарегистрируйтесь (email/пароль или через Google)
3. Ключ появится сразу на дашборде — скопируйте его

## Шаг 2. Добавить файлы в репозиторий
Точно так же, как раньше — через "Add file → Create new file" с указанием
полного пути:
- `weekly_market_prep.py` (в корне репозитория)
- `.github/workflows/weekly_market_prep.yml`

Секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` уже есть в репозитории —
их трогать не нужно.

## Шаг 3. Добавить ещё один секрет
Settings → Secrets and variables → Actions → New repository secret:
- Name: `TWELVE_DATA_API_KEY`
- Secret: ключ из шага 1

## Шаг 4. Проверить вручную
Actions → выбрать workflow "Weekly Market Prep Report" → Run workflow.
Через минуту проверьте Telegram — должно прийти отдельное сообщение с
календарём, диапазонами и уровнями.

## Важно про источники данных
- **Календарь** — неофициальный, но давно и широко используемый в трейдерском
  сообществе бесплатный фид Forex Factory. Если он временно недоступен или
  поменяет формат, в отчёте просто появится "нет данных" по календарю — на
  остальные разделы это не повлияет.
- **Диапазоны/уровни** — Twelve Data, бесплатный тариф: 800 запросов/день,
  8/минуту. Скрипт делает всего 2 запроса за раз, так что лимит не проблема.
  Alpha Vantage изначально тоже рассматривался, но его функция для валютных
  пар не поддерживает золото (XAU) — поэтому оба инструмента идут через
  Twelve Data, один провайдер вместо двух.
